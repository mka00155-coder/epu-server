# سیستەمی تۆماری ئامادەبوونی فەرمانبەران — EPU (وەشانی سێرڤەر)

ئەم وەشانە **داتابەیسی ڕاستەقینەی هاوبەشی** هەیە (Node.js + Neon Postgres). واتا:
هەموو گۆڕانکارییەک کە هەر بەکارهێنەر یان ئادمینێک دەیکات، لەسەر **هەموو ئامێرەکان** دەردەکەوێت
کە پەیوەست بن بە هەمان سێرڤەرەوە — نەک تەنها لەسەر یەک کۆمپیوتەر یان یەک براوسەر.

---

## پێداویستییەکان

- **Node.js نەشخەی 18 یان بەرزتر** — دایبگرە لە https://nodejs.org

---

## دامەزراندن (یەک جار)

1. فۆڵدەری `epu-server` بخە لەسەر ئەو کۆمپیوتەرەی دەبێتە سێرڤەر.
2. تێرمیناڵ/CMD بکەرەوە لەناو فۆڵدەرەکەدا و ئەمە بنووسە:

```bash
npm install
```

ئەمە پاکێجەکان (express و better-sqlite3) دادەبەزێنێت. (جارێک ئینتەرنێتی پێویستە بۆ ئەم هەنگاوە.)

---

## کارپێکردنی سێرڤەر

```bash
npm start
```

پاشان ئەم پەیامە دەردەکەوێت:

```
سێرڤەر کارایە لەسەر:  http://localhost:3000
```

- **لەسەر هەمان کۆمپیوتەر:** براوسەر بکەرەوە و بڕۆ بۆ `http://localhost:3000`
- **لە کۆمپیوتەرەکانی تر (هەمان تۆڕ/وایفای):** بڕۆ بۆ `http://<IP-ی سێرڤەر>:3000`
  بۆ زانینی IP لەسەر ویندۆز: `ipconfig` بنووسە و بڕوانە `IPv4 Address` (نموونە `192.168.1.20`).

> سێرڤەرەکە دەبێت هەمیشە کارا بێت تاکو ئامێرەکانی تر بتوانن پەیوەست بن.

---

## زانیاری چوونەژوورەوەی بنەڕەتی

| بەکارهێنەر | پاسوۆرد    | جۆر            |
|-----------|-----------|----------------|
| `MKA95`   | `0155`    | بەڕێوەبەری سەرەکی |
| `DARYA`   | `123456789` | ئادمینی ئاسایی |

بەڕێوەبەری سەرەکی دەتوانێت لە پانێڵی «بەڕێوەبردن»:
- ئادمینی نوێ زیاد/سڕینەوە و دەسەڵاتەکانیان دیاری بکات.
- ناوی زانکۆ و پەیمانگا بگۆڕێت.
- باکئەپ دروست بکات و بیگەڕێنێتەوە.

---

## داتاکان لەکوێ پارێزراون؟

هەموو داتاکان لە فایلی `attendance.db` (لەناو فۆڵدەری سێرڤەر) پارێزراون.
بۆ باکئەپی دەستی، تەنها ئەم فایلە کۆپی بکە — یان لە سیستەمەکەوە دوگمەی «باکئەپ» بەکاربهێنە.

---

## تایبەتمەندییەکان

- داتابەیسی هاوبەش بۆ هەموو ئامێرەکان (Node.js + Neon Postgres).
- سێ بەش: گرێبەست، هەمیشەیی، کارگوزار.
- هەڵبژاردنی ماوە: هەفتەیەک، مانگێک، سێ مانگ، شەش مانگ — یان بەروارە دەستیەکان.
- ڕێگری لە هەڵبژاردنی ڕۆژی هەینی/شەممە + ڕێکخستنی خۆکاری بۆ یەکشەممە.
- گۆڕینی ناوی زانکۆ/پەیمانگا (تەنها بەڕێوەبەری سەرەکی).
- دیارکردن/شاردنەوەی ناوی بەش لەسەر خشتەکان.
- چاپکردن/PDF ڕوون و پڕۆفیشناڵ.
- گەڕان، هەناردە/هاوردەی CSV، باکئەپ/گەڕاندنەوە.
- ڕووکاری ڕووناک/تاریک، پاڵپشتی مۆبایل.

---

## تێبینی ئاسایش

- پاسوۆردەکان بەشێوەی سادە پارێزراون تاکو بەڕێوەبەری سەرەکی بتوانێت بیانبینێت و ڕیسێت بکات.
  بۆ بەکارهێنانی گشتی لەسەر ئینتەرنێت، پێشنیار دەکرێت HTTPS و هاشکردنی پاسوۆرد زیاد بکرێت.
- ئەم سیستەمە بۆ بەکارهێنان لەناو تۆڕی ناوخۆیی (LAN) داڕێژراوە.

---

## کێشەکان

- **«پەیوەندی بە سێرڤەرەوە نەکرا»** → دڵنیابە `npm start` کارا بێت و IP/پۆرت ڕاست بێت.
- **پۆرتی 3000 داگیرکراوە** → پۆرتێکی تر بەکاربهێنە: `PORT=4000 npm start` (ویندۆز: `set PORT=4000 && npm start`).
- **کێشە لە `npm install` (better-sqlite3)** → دڵنیابە Node نەشخەی 18/20/22ی LTS بەکاردەهێنیت (ئەمانە بایناری ئامادەیان هەیە و پێویستیان بە کۆمپایل نییە). ئەگەر هێشتا کێشە هەبوو، لەسەر ویندۆز `npm install --global windows-build-tools` نەکە — تەنها Node LTS دووبارە دابگرە.
