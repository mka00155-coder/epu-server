# سیستەمی تۆماری ئامادەبوونی فەرمانبەران — EPU

وەشانی سێرڤەر: **Node.js + Express + Neon Postgres**. داتاکان لە داتابەیسێکی هاوبەشدا دەپارێزرێن، بۆیە هەموو گۆڕانکارییەک
لەسەر **هەموو ئامێرەکان** دەردەکەوێت (کۆمپیوتەر، مۆبایل، سکانکەر).

> بۆ بڵاوکردنەوە لەسەر ئینتەرنێت (Neon + Render) بڕوانە [`DEPLOY.md`](DEPLOY.md).

---

## پێکهاتەی پڕۆژە

```
server.js          سێرڤەر + API (Express + pg)
public/
  index.html       ڕووکاری تەواو (یەک پەڕە)  ← بۆ گۆڕینی ڕووکار ئەمە دەستکاری بکە
  logo.png         لۆگۆی EPU
package.json
legacy/            وەشانی کۆنی ئۆفلاین (IndexedDB) — تەنها بۆ ئارشیف، بەکارنایەت
```

**تێبینی گرنگ:** سێرڤەر `public/index.html` دەخوێنێتەوە لە دەستپێکدا. ئەگەر فۆڵدەری `public` لەگەڵ `server.js` بار نەکرێت،
سێرڤەر دەست پێ ناکات و لە لۆگەکەدا پەیامی ڕوون دەنووسێت.

---

## کارپێکردن لەسەر کۆمپیوتەری خۆت

پێویستی: **Node.js 18 یان نوێتر** + داتابەیسێکی Postgres (Neon بەخۆڕایی بەسە).

```bash
npm install
DATABASE_URL="postgresql://USER:PASS@HOST/DB?sslmode=require" npm start
```

ویندۆز (CMD):

```bat
set DATABASE_URL=postgresql://USER:PASS@HOST/DB?sslmode=require
npm start
```

پاشان بکەرەوە: `http://localhost:3000`

### گۆڕاوەکانی ژینگە (Environment variables)

| ناو | پێویستە؟ | ڕوونکردنەوە |
|---|---|---|
| `DATABASE_URL` | بەڵێ | connection string ی Postgres/Neon |
| `PORT` | نەخێر | پۆرت (بنەڕەت `3000`) |
| `SESSION_DAYS` | نەخێر | چەند ڕۆژ بەبێ بەکارهێنان تا سێشن بەسەربچێت (بنەڕەت `30`) |
| `DATABASE_SSL` | نەخێر | `false` بۆ Postgresـی ناوخۆیی بێ SSL (Neon پێویستی بە SSL هەیە، بۆیە دایمەنێ) |

## یەکەم جار

داتابەیس خۆکارانە ئامادە دەبێت و ئەم ئەکاونتانە دروست دەکرێن: بەڕێوەبەری سەرەکی `MKA95` و ئادمینێکی ئاسایی `DARYA`
(پاسوۆردی بنەڕەتی لە `DEFAULT_ADMINS`ی ناو `server.js` دایە).

**دوای یەکەم چوونەژوورەوە، بەپەلە پاسوۆردەکان بگۆڕە** (بەشی «بەڕێوەبردن»). ئەگەر پڕۆژەکە لە GitHubی گشتی دایە، ئەو
پاسوۆردانە بۆ هەمووان دیارن.

## تایبەتمەندییەکان

- سێ بەش: گرێبەست، هەمیشەیی، کارگوزار؛ خشتەی چاپ/PDF لەگەڵ تەمپلێتی جیاواز و لاپەڕەی بەرگ.
- پرۆفایلی فەرمانبەر، کارتی ID (QR + بارکۆد)، داگرتنی هەموو کارتەکان وەک ZIP.
- **سکانی QR** بۆ هاتن/ڕۆیشتن (بەیانیان/ئێوارە) — کات هەمیشە لە سێرڤەرەوە دێت (کاتی عێراق).
- ڕاپۆرتی ئامادەبوون، مۆڵەت (خوێندن/منداڵبوون/کتوپڕ)، مێژووی چالاکی، هەناردەی CSV.
- ئادمینی جیاواز بە دەسەڵاتی جیاواز (زیادکردن، سڕینەوە، دەستکاری، چاپ، پرۆفایل، سکان، ڕاپۆرت).
- ڕووکاری ڕووناک/تاریک، پاڵپشتی مۆبایل.

## باکئەپ و گەڕاندنەوە (بەشی «بەڕێوەبردن» — تەنها بەڕێوەبەری سەرەکی)

باکئەپی **وەشانی ٤** ئەمانە دەگرێتەوە: فەرمانبەران، ئادمینەکان و دەسەڵاتەکانیان، ڕێکخستنەکان، **تۆماری ئامادەبوون و مۆڵەتەکان**.
(مێژووی چالاکی `audit_log` لە باکئەپدا نییە.)

- گەڕاندنەوە **یەک مامەڵەیە**: ئەگەر فایلەکە هەڵە بێت هیچ نایگۆڕێت.
- ID ی فەرمانبەران دەپارێزرێت، بۆیە تۆمارەکانی ئامادەبوون هەر بە هەمان کەسەوە دەمێننەوە.
- گەڕاندنەوە ڕەت دەکرێتەوە ئەگەر فایلەکە هیچ بەڕێوەبەرێکی سەرەکی تێدا نەبێت (بۆ ئەوەی کەس دەرنەکەوێت).
- باکئەپی کۆنی وەشانی ٣ هێشتا دەگەڕێتەوە (بەڵام ئەوانە تۆماری ئامادەبوونیان تێدا نییە).

## ئاسایش

- سێشنەکان لە داتابەیس دەپارێزرێن (تەنها hashی تۆکن)؛ دوای `SESSION_DAYS` ڕۆژ بێ بەکارهێنان، یان ٩٠ ڕۆژ بە گشتی، بەسەردەچن.
  گۆڕینی پاسوۆرد یان سڕینەوەی ئادمین، سێشنەکانی ئەو ئادمینە دەسڕێتەوە.
- ٨ هەوڵی هەڵەی چوونەژوورەوە لە ١٠ خولەکدا = بلۆک بۆ ١٠ خولەک (هەر IP + بەکارهێنەر).
- کلیلی ImgBB تەنها بۆ بەڕێوەبەری سەرەکی و ئەو ئادمینانە دەگەڕێتەوە کە دەسەڵاتی پرۆفایلیان هەیە.
- **پاسوۆردەکان هێشتا بە شێوەی سادە هەڵدەگیرێن** (بۆ ئەوەی بەڕێوەبەری سەرەکی بتوانێت ببینێت/ڕیسێتیان بکات). بۆ بەکارهێنانی گشتی
  لەسەر ئینتەرنێت پێشنیار دەکرێت هاش بکرێن.

## کێشەکان

- **«پەیوەندی بە سێرڤەرەوە نەکرا»** → دڵنیابە سێرڤەر کارایە و `DATABASE_URL` ڕاستە.
- **«DATABASE_URL دانەنراوە»** → گۆڕاوەکە دابنێ و دووبارە دەستپێبکەرەوە.
- **سێرڤەر دەست پێ ناکات و باسی `public/index.html` دەکات** → فۆڵدەری `public` بار بکە.
- **پۆرتی 3000 داگیرکراوە** → `PORT=4000 npm start` (ویندۆز: `set PORT=4000 && npm start`).
- **سکان کار ناکات** → ڕێگە بە کامێرا بدە؛ کتێبخانەی سکان لە CDN بار دەبێت، بۆیە ئینتەرنێت پێویستە.
